# FlowGuard Agent 测试文档

## 项目背景

FlowGuard Agent 是一个 workflow-first 的执行型 AI Agent 框架，专门设计用于多设备、多系统的任务编排与冲突处理场景。

## 核心设计原则

1. **防止假完成**：模型不能在没有执行工具的情况下声称"已完成"
2. **防止跳步**：每一步必须有计划、执行结果和日志
3. **高风险确认**：门锁、摄像头、删除操作必须用户显式确认
4. **冲突检测**：自动检测多设备状态冲突（如窗户开着时不应开空调）
5. **全程可追溯**：所有工具调用写入 execution_log.json

## 支持的设备类型

| 设备 | 风险级别 | 需要确认的操作 |
|------|----------|--------------|
| door_lock | high | 解锁 |
| camera | high | 关闭 |
| air_conditioner | low | 无 |
| light | low | 无 |
| curtain | low | 无 |
| robot_vacuum | low | 无 |
| window | low | 无 |

## 冲突规则示例

- 窗户开启时不建议开启空调（能效冲突）
- 安防模式开启时不应解锁门锁（安全冲突）
- 打扫模式下不应执行回家模式（状态冲突）

## 回家模式执行流程

1. 读取当前设备状态
2. 生成执行计划
3. 检测状态冲突
4. 执行低风险动作（开灯、开空调、暂停扫地机器人）
5. 高风险动作（解锁门锁）等待用户确认
6. 写入执行日志
7. 返回执行摘要
